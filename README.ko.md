# HWP Desk 안드로이드

HWP·HWPX·PDF·엑셀 파일을 휴대폰에서 열고 내용을 수정하는 앱입니다. Android 8.0 이상에서 동작하며 서버·로그인·API 키가 필요 없습니다. 인터넷 권한도 요청하지 않습니다.

| 형식 | 확인·수정 기능 | 저장 형식 |
| --- | --- | --- |
| HWP 5 | 본문·표 셀·머리말·꼬리말·각주의 텍스트 확인, 검색, 수정 | HWP |
| HWPX | 본문과 표의 일반 텍스트 확인·수정 | HWPX |
| PDF | 원본 페이지 보기, 한글 글자 추가, 펜 필기, 되돌리기 | PDF |
| XLSX | 시트 전환, 셀 주소 이동, 값·수식 확인 및 수정 | XLSX |
| XLS | 구형 엑셀 셀·수식 확인·수정 | XLS |

**파일 열기**로 문서를 선택하고 문단이나 셀을 누르면 수정할 수 있습니다. PDF는 펜을 켜서 필기하거나 글자를 입력한 뒤 페이지에서 위치를 누릅니다. 펜을 끄면 스크롤할 수 있습니다. **수정본 저장**을 눌러 새 파일로 내보냅니다.

## APK 빌드·설치

Android Studio, JDK 17, SDK 35, Gradle 8.9를 사용합니다.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows에서는 `gradlew.bat testDebugUnitTest lintDebug assembleDebug`를 실행합니다.

APK 위치: `app/build/outputs/apk/debug/app-debug.apk`

메인에 푸시하면 [GitHub Actions](../../actions)의 **Android APK**에서 자동 빌드합니다. 성공한 실행의 **HWP-Desk-debug-apk**를 다운로드하고 압축을 풀어 APK를 설치하세요. 개인 테스트용 디버그 서명이며 정식 배포에는 별도의 고정 서명 키가 필요합니다.

## 실제 지원 범위

- 한글·엑셀은 **내용 중심 보기**입니다. 인쇄 화면과 동일한 배치를 재현하지 않습니다. PDF는 원본 페이지를 표시합니다.
- HWP의 표·제어 개체·첨부 이미지는 유지하며 텍스트를 수정합니다. 수정된 텍스트는 시작 지점의 글자 스타일을 이어받으므로 해당 부분의 혼합 서식은 바뀔 수 있습니다. 줄·페이지 배치는 한글에서 다시 열 때 재계산됩니다. 문단 추가·삭제, 도형 편집은 지원하지 않습니다. 영역 태그가 있는 텍스트는 읽기 전용입니다. HWP 5 이전 버전, 암호·배포용 문서는 지원하지 않습니다.
- HWPX에서 제어 개체를 포함한 텍스트 노드는 읽기 전용입니다. 일반 텍스트 노드만 수정하고 나머지 파일 구성은 보존합니다.
- PDF의 기존 본문을 재작성하지 않습니다. 글자·필기를 투명 이미지로 원본 페이지 위에 추가합니다. 한글 글자는 기기 글꼴로 렌더링합니다. 암호·수정 제한 PDF와 일부 JPX 이미지는 지원하지 않으며 수정 후 기존 전자서명은 유효하지 않습니다.
- XLSX의 다른 구성 항목과 셀 서식 ID는 유지합니다. 수식은 `=`로 입력하며 앱에서 계산하지 않습니다. Excel에서 다시 열 때 재계산합니다. 공유·배열 수식 영역, 보호 시트, Strict OOXML은 지원하지 않습니다. 병합 셀·차트·이미지를 화면 그대로 표시하지 않으며 XLSX의 차트·이미지 파일은 보존합니다.
- XLS는 JExcelAPI로 복사 저장합니다. 복잡한 도형·매크로·일부 구형 기능은 보존을 보장하지 않으므로 수정본을 Excel에서 확인해야 합니다.
- 앞에 0이 있는 번호와 15자리를 넘는 숫자는 텍스트로 저장합니다. XLSX 날짜는 저장된 값으로 표시됩니다. 셀 서식 편집과 앱 내 수식 계산은 지원하지 않습니다.
- 입력 파일은 64MB까지, 압축 해제 크기는 128MB까지 지원합니다. 수정 내용은 내보내기 전까지 메모리에 있어 앱 프로세스가 종료되면 사라집니다. 정상적으로 문서를 닫으면 작업용 복사본을 삭제합니다.

## 검증

HWP의 유니코드·제어 개체와 반복 수정, HWPX 마크업, XLSX의 다른 셀·서식·구성 파일과 재계산 설정, XLS 반복 저장, XML·셀 주소 검사를 자동 테스트합니다. CI에서 단위 테스트·Android lint·APK 컴파일을 실행합니다. 정식 배포 전 실제 기기의 화면·입출력 검증이 필요합니다.
