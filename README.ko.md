# HWP Desk 안드로이드

HWP·HWPX·PDF·엑셀 파일을 휴대폰에서 열고 내용을 수정하는 앱입니다. Android 8.0 이상에서 동작하며 서버·로그인·API 키가 필요 없습니다. 인터넷 권한도 요청하지 않습니다.

| 형식 | 확인·수정 기능 | 저장 |
| --- | --- | --- |
| HWP·HWPX | 텍스트·찾기/바꾸기·글꼴·크기·굵게·정렬, 문단 추가/삭제, 표·이미지 레이아웃 보기 | 원래 형식·PDF |
| PDF | 글자·펜·투명 서명 이미지, 크기·위치 선택, 페이지 회전·삭제·순서·병합·추출 | PDF |
| XLSX·XLS | 셀·수식·계산 결과, 글꼴·크기·굵게·정렬, 숫자·금액·날짜·백분율, 찾기/바꾸기 | 원래 형식 |

**모든 편집을 자동저장**하고, 앱을 다시 열면 마지막 문서를 복구합니다. 상단 ↶/↷ 버튼으로 최대 20개의 변경 기록을 이동합니다. 새 문서를 열면 복구 기록도 새 문서로 바뀝니다. 복구 파일은 앱 전용 저장 공간에 보관하고, 도구 메뉴에서 삭제할 수 있습니다.

문단·셀을 누르면 편집 메뉴가 나옵니다. **도구**에서 전체 찾기/바꾸기, 한글 레이아웃·PDF 저장, PDF 페이지 관리를 사용하세요. 서명은 투명 PNG 등을 선택하고 페이지 대비 너비(%)를 입력한 뒤 원하는 위치를 누릅니다. 삽입 후 위치·크기를 바꾸려면 실행 취소하고 다시 삽입하세요.

## APK 빌드·설치

Android Studio, JDK 17, SDK 35, Gradle 8.9를 사용합니다.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Windows에서는 `gradlew.bat testDebugUnitTest lintDebug assembleDebug`를 실행합니다.

APK 위치: `app/build/outputs/apk/debug/app-debug.apk`

메인에 푸시하면 [GitHub Actions](../../actions)의 **Android APK**에서 자동 빌드합니다. 성공한 실행의 **HWP-Desk-debug-apk**를 다운로드하고 압축을 풀어 APK를 설치하세요. 개인 테스트용 디버그 서명이며 정식 배포에는 별도의 고정 서명 키가 필요합니다.

## 실제 지원 범위

- **자체 한글 렌더러**로 용지 크기·여백·글자 서식·표 열 너비·내장 이미지를 읽어 페이지로 배치하고 실제 PDF 파일을 생성합니다. 한컴 엔진과 동일한 원본 재현은 아닙니다. 글자 감싸기, 떠 있는 개체, 행 병합·복잡한 테두리, 수식·벡터 도형·다단 배치는 차이가 나거나 지원되지 않습니다. 행 병합은 행별로 펼치고, 머리말·꼬리말·각주는 본문 흐름에 표시합니다. 감지한 제한은 미리보기 화면에 안내합니다.
- 기기에 없는 글꼴은 대체됩니다. 원본 파일에는 지정한 글꼴 이름을 저장합니다. 줄·페이지는 다시 배치합니다. HWP 서식 적용은 해당 문단 전체, HWPX 글자 서식은 해당 텍스트 run과 문단 정렬에 적용됩니다. HWP 원본 형식 저장 시 표·제어 개체·내장 자료를 유지합니다.
- HWP 5 이전 버전, 암호·배포용 문서는 지원하지 않습니다. 영역 태그 텍스트와 제어 개체가 있는 HWPX 텍스트는 읽기 전용입니다. 구조 개체가 있는 문단이나 컨테이너의 마지막 문단은 삭제할 수 없습니다. 찾기/바꾸기는 수정 가능한 텍스트 단위에서 작동하며 별도 run을 가로지르는 검색은 지원하지 않습니다.
- PDF 글자·필기·서명은 원본 위에 추가해 저장합니다. 기존 PDF 본문 자체는 재작성하지 않습니다. 편집 기록마다 내용을 고정한 PDF를 저장하고 실행 취소로 이전 상태를 복구합니다. 추출은 선택한 페이지를 별도 PDF로 저장하며, 범위를 나눠 반복하면 문서를 분할할 수 있습니다. 암호·수정 제한 PDF, 일부 JPX 이미지, 전자서명 유효성 유지는 지원하지 않습니다. 병합·재정렬 후 목차·페이지 라벨은 갱신하지 않습니다.
- 엑셀 계산은 사칙연산·거듭제곱·백분율·비교·문자열 결합, 같은/다른 시트 참조, 제한된 범위를 지원합니다. 함수는 `SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`, `IF`, `IFERROR`, `ROUND`, `ABS`, `AND`, `OR`입니다. 미지원 함수는 `#UNSUPPORTED(함수명)`, 순환 참조는 `#CYCLE!` 등으로 표시합니다. 전체 Excel 계산 엔진은 아니며, 내보낸 파일은 Excel에서 다시 계산합니다.
- 엑셀 날짜·숫자·금액·백분율 표시와 기본 서식을 지원합니다. 복잡한 사용자 서식은 근사 표시합니다. XLSX 차트·이미지 파일은 보존하지만 화면에 표시하지 않으며 병합 셀은 내부 셀로 표시합니다. 공유·배열 수식 영역 편집, 보호 시트, Strict OOXML은 지원하지 않습니다. 찾기/바꾸기는 값에 적용하며 수식은 바꾸지 않습니다. 앞에 0이 있는 번호나 15자리를 넘는 숫자는 텍스트로 유지합니다.
- XLS는 JExcelAPI로 저장하므로 일부 구형 도형·매크로를 보존하지 못할 수 있습니다. 해당 파일은 Excel에서 확인하세요.
- 입력은 64MB, 압축 해제는 128MB/10,000개 구성 항목, PDF 배치·병합은 300페이지까지입니다. 자동저장 한 파일은 96MB까지 지원하며 변경 기록은 최대 20개·총 192MB를 기준으로 오래된 항목부터 정리합니다. 현재 기록 하나는 유지합니다. 저장에 실패하면 직전 기록으로 복구합니다. 적용 전 입력창이나 끝내지 않은 필기는 기록하지 않습니다. 앱 데이터 삭제·앱 제거 시 복구 파일도 삭제됩니다.

## 검증

HWP/HWPX의 서식·문단 변경·유니코드·제어 개체 보존, XLSX 서식·날짜·수식 계산·오류, XLS 반복 저장, 자동 복구·되돌리기·저장 실패, XML·페이지 범위를 테스트합니다. 안드로이드 테스트에서는 PDF 회전·자르기 좌표·서명·페이지 관리와 한글 PDF 렌더링을 검사합니다. CI에 테스트·lint·APK 빌드·에뮬레이터 검증을 포함합니다.
